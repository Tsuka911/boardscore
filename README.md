# 🎲 ボドゲ得点計算

ボードゲームの得点計算をラクにするアプリ集。**インターネット接続もサーバーも不要**で、
HTMLファイルを開くだけで動きます。

## ファイル構成

| ファイル | 中身 |
|---|---|
| `index.html` | **メニュー画面**（ここから開く） |
| `sushigo.html` | SUSHI GO!（オリジナル版）専用の得点計算 |
| `score.html` | どんなゲームにも使える汎用の得点表 |

## 使い方

**公開URL: https://tsuka911.github.io/boardscore/**

### iPhoneで使う
Safariで上のURLを開くだけです。
「共有ボタン → ホーム画面に追加」しておくと、鮭にぎりのアイコンから
アプリのようにワンタップで起動できます。

> ⚠️ **iCloud Driveにファイルを置いて「ファイル」アプリから開く方法は使えません。**
> iOSではローカルのHTMLがクイックルック（プレビュー）で開かれてしまい、
> ページ間のリンクが動かず、得点の保存も効かないためです。
> iPhoneではSafariでローカルファイル（file://）を開く手段がありません。

### Macで使う
`index.html` をダブルクリックすればローカルのファイルのまま開けます
（Macはローカルファイルでも問題なく動きます）。上の公開URLからでも同じように使えます。

## 🍣 SUSHI GO!（sushigo.html）

カードの枚数を入れるだけで得点が出ます。

- **カードの絵は水彩風のイラスト**（`Codex 画像 ....png` から切り出したもの。HTMLファイルの中に埋め込んであるので、画像ファイルを一緒に持ち歩く必要はありません）
- **プレイヤーごとに色分けした駒**（人型のマーク）が、名前の出るところすべてに付きます
- **枚数の右に、そのネタで稼いだ点数を表示**（天ぷら1枚なら0点、2枚で +5点）
- **「あと1枚で +5点」**と、もう1枚取ると何点増えるかも表示（緑の文字）
- 巻きは全員の入力から順位を計算して「現在1位」「1位まであと3本」などを表示
- プリンは3ラウンド合計で決まるので「暫定」と付けて表示
- 3ラウンド終わると順位とラウンド別の内訳が出ます
- 箸（チョップスティック）は得点にならないので入力項目にはありません

### 得点ルール（オリジナル版）

| カード | 得点 |
|---|---|
| 巻き | 各ラウンドで本数1位が6点、2位が3点。同点は山分け（切り捨て）。1位が複数のときは2位の得点なし。0本の人は対象外 |
| 天ぷら | 2枚1組で5点 |
| 刺身 | 3枚1組で10点 |
| 餃子 | 1枚1点 / 2枚3点 / 3枚6点 / 4枚10点 / 5枚以上15点 |
| にぎり | 玉子1点・鮭2点・イカ3点 |
| わさび | 上に置いたにぎりが3倍（玉子3点・鮭6点・イカ9点） |
| プリン | 3ラウンド合計で最多6点、最少−3点（山分け）。2人プレイでは−3点なし |

※プリンのマイナスを山分けする際の端数は、プレイヤーに有利な側（例: 2人で分けたら −1 ずつ）にしています。
※全員のプリンが同数のときは、マイナス点はつけず 6点の山分けのみとしています。

## 📋 汎用の得点表（score.html）

行＝プレイヤー、列＝ラウンドの表に点数を入れていくだけのシンプルな得点表です。

- **マスをタップするとテンキー**が出ます。「＋足す」を押せば、今の点に足し算もできます（`4 + 5 = 9` のように途中式が見えます）
- マイナス点も入力できます（`±` ボタン）
- **合計と順位はその場で自動計算**。1位の行は色が付きます
- **列の名前は自由に変更できます**。「R1」のままラウンド表としても、「農地」「勝利点」のように得点項目の表としても使えます
- 「点が少ない方が勝ち」のゲームにも切り替えで対応
- プレイヤーは2〜8人。**ゲームの途中で名前を直したり人を追加しても、それまでの点数はそのまま残ります**

### 便利な使い方
- テンキーの「決定して次の人 →」を押すと、そのまま次のプレイヤーの入力に移るので、ラウンド終わりの一括入力が速いです

## メモ

- 入力内容はブラウザに自動保存されるので、途中で閉じても続きから再開できます（2つのアプリは別々に保存されるので、お互いに消し合いません）
- 「新規」ボタンなど、データが消える操作の前には必ず確認が出ます

## カードの絵を差し替えたいとき

`sushigo.html` の中の `const ICON = { ... }` に、画像データが直接書き込まれています。
差し替えたい絵があれば、その画像をフォルダに置いて「これに変えて」と伝えてください。

プレイヤーの駒（人型のマーク）は `PAWN_COLORS` と `pawn()` で作っています。
色を変えたいときはここを直します。
